# Sports Equipment Management System

1. Requires Python 3 (Tkinter and SQLite are built in, nothing to install).
2. Run the app: `python app.py`
3. The database `sports.db` is created automatically from `schema.sql` on first run.
4. `queries.sql` holds the sample queries, and `sample_import/equipment.csv` can be loaded with Import CSV on the Equipment screen.
